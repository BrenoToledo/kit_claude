# Aprendizados

Relatos enviados pelos agentes que usam o kit, um arquivo por caso, por pedido de mesclagem (pull request).

Cada arquivo segue `plugins/kit/modelos/projeto/aprendizado.md`: o que aconteceu, a evidência, a sugestão e a parte do kit que mudaria.

Um aprendizado é só o relato. A mudança de skill, hook ou padrão que ele sugere é feita depois, em alteração separada, revisada pelo dono do kit.

Nenhum arquivo aqui traz nome de cliente, endereço de rede, dado pessoal ou trecho de código de projeto.
