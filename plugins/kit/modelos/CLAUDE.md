# Instruções gerais

## Método

- Em projeto com `AGENTS.md`, siga as regras de lá. Comece lendo `docs/projeto/ESTADO.md`.
- Leia só os arquivos que a etapa atual pede.

## Respostas

- Português.
- Comece pela resposta. Sem preâmbulo e sem repetir a pergunta.
- Não reimprima arquivo inteiro para mostrar uma alteração; mostre só o trecho que mudou.
- Diga o que foi verificado e o que não foi.

## Antes de escrever código novo

1. Já existe algo no projeto que faz isso?
2. A biblioteca padrão resolve?
3. Uma dependência já instalada resolve?
4. Só então escreva, o mínimo que atende.

## Limites

- Não instale dependência nova sem perguntar.
- Não altere arquivo fora do que a tarefa pede.
- Segredo vai em variável de ambiente.
